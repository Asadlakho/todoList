📝 TodoList Project :

A simple and responsive Todo List App built using HTML, JavaScript, and Tailwind CSS.
This mini project allows users to add and remove tasks easily with a clean, modern UI.

🚀 Features :

➕ Add new tasks to your list

❌ Remove completed or unwanted tasks

💾 Data managed dynamically using JavaScript

🎨 Beautiful and fully responsive UI designed with Tailwind CSS

⚡ Fast, lightweight, and beginner-friendly project

🛠️ Technologies Used :

.HTML5

.Tailwind CSS

.JavaScript (DOM Manipulation)
